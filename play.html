name of game: Flower RUN 2.0

flower run 2.0

2023

Game Design, Final Project

playtest version 2.0

My role for this particular project was as a designer and game developer. My game Flower Run is in it’s 2.0 version and it is a simple game that is reminiscent of the classic Mario Brothers game. The game's objective is to collect flowers and navigate through different obstacles and enemies like the red wasp to reach the goal of reaching the friendly queen bee. The game is designed with basic mechanics that are easy to understand, making it a stress free and a game for all ages. The levels become progressively more challenging as the player advances. For the 2.0 series, additional games of music/ noises were added and different weather backgrounds added a new layer of immersion, making the game more engaging and enjoyable to play.
